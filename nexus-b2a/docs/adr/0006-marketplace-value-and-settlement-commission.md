# Earn marketplace commission on completed transactions

Accepted during the design interview. Nexus's proposition includes comparable seller discovery, a consistent purchasing contract, Nexus-enforced budgets, transaction history, and consistent failure handling across sellers. Agent-exclusive positioning is part of the presentation, not the complete customer value proposition.

Nexus earns a configurable seller commission only when the transaction completes through contract-valid delivery as previously agreed. The buyer's total, Nexus fee, and seller net proceeds are disclosed before commitment and locked in the order terms. Expired or failed orders earn no commission. The first prototype represents settlement in test credits; neither a commission rate nor live payment integration has been chosen.

The initial demonstration may use services operated by the builders, but MVP completion requires an outside developer to register a compatible seller and an independently built buyer to purchase through the documented interface without changes to Nexus core code. Fifteen minutes using a prepared example is an integration target to measure, not an achieved result.
