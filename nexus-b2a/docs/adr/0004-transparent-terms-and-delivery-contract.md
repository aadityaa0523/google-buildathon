# Settle against transparent locked terms and checkable delivery rules

Accepted during the design interview. The buyer agent chooses among comparable seller offers. Nexus supplies filtering and comparison; ranking must expose its basis and must not invent quality evidence. The full fixed price, input limits, output schema, required checks, and deadline are disclosed before commitment and locked when the order is accepted. A seller cannot change those terms or add token charges mid-job.

Nexus releases reserved test credits for contract-valid delivery: a result passes the advertised checks within the agreed deadline. This is not a blanket guarantee of semantic accuracy. Semantic accuracy is evaluated separately; syntactically valid JSON can still contain an incorrect extracted value. The exact initial schema and check set remain to be specified.

Discovery does not send buyer documents to competing sellers. Only the selected seller receives authorized job input after purchase authorization. Raw documents are excluded from public listings and routine logs. Detailed retention/deletion rules, timeout/retry semantics, and any post-settlement dispute/refund policy remain open.
